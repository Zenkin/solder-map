# SolderMap

Локальная карта пайки для Windows, Linux и macOS на Electron.

## Работа с платой

1. Создайте проект или откройте папку с существующим `project.json`.
2. Выберите **TOP** или **BOTTOM** и загрузите изображение этой стороны.
3. В режиме **Разметка** нажмите **＋ Компонент** и нарисуйте область. Задайте обозначение, номинал, корпус и при необходимости этап, группу и заметку. Область можно перемещать и менять за нижний правый угол.
4. Перейдите в режим **Пайка**. Во вкладке **По номиналам** партии идут по убыванию оставшегося количества: удобно начинать с наиболее многочисленных компонентов.
5. Выберите компонент и нажмите **Отметить припаянным** (или Enter). Синяя область означает «Ожидает пайки», зелёная — «Припаян». Повторная команда снимает отметку.

Кнопка **Снять все отметки пайки** в верхней панели сбрасывает пайку у всех компонентов проекта на TOP и BOTTOM, независимо от текущих фильтров. Действие требует подтверждения и отменяется через **Ctrl+Z**.

ПКМ по компоненту → **Показать такой же номинал** показывает всю партию только на текущей стороне. Поиск и остальные фильтры при этом сбрасываются. Панель партии содержит обозначения и оставшееся количество; можно отметить оставшиеся компоненты одной командой с подтверждением.

Резисторы и конденсаторы с эквивалентными номиналами объединяются: `10k`, `10 кОм`, `10000 Ohm`; `0.1µF`, `100 нФ`. Разные типы компонентов остаются отдельными партиями. Дополнительная сортировка — по общему количеству или номиналу.

Поиск работает по обозначению, номиналу, типу/корпусу, группе и заметке. Можно вводить несколько обозначений: `R1, R5, R12`. Фильтры стороны, состояния пайки, этапа и группы применяются совместно.

Запрос с единицами, например **1 кОм**, сравнивает номинал точно: **1,5 кОм**, **10 кОм** и **191 кОм** не попадут в результаты. Номинал распознаётся и внутри полного описания `0.1Вт 0603 1 кОм, 0.1%`; мощность, корпус и процент не участвуют в его сравнении. Исходное описание сохраняется. Можно уточнить запрос: `1 кОм 0603`.

## Масштаб и клавиатура

- Колесо мыши — масштаб относительно курсора, диапазон 5–800%.
- Пробел + перетаскивание или средняя кнопка мыши — перемещение платы.
- Кнопки **−**, **＋**, ползунок, **100%** и **Вписать** управляют масштабом.
- **Ctrl+F** — поиск; **Ctrl+S** — сохранить; **Ctrl+Z / Ctrl+Y** — отменить / повторить.
- **Enter** — изменить отметку выбранного компонента; **Delete** в режиме разметки — удалить его.

## Проводник

Встроенный проводник показывает файлы и папки в виде таблицы или плиток, с поиском, сортировкой, адресной строкой, переходами назад/вперёд/вверх, цепочкой папок, местами и дисками. Длинные имена переносятся внутри строки.

- Выделение: Ctrl — отдельные элементы, Shift — диапазон, Ctrl+A — все.
- Ctrl+C / Ctrl+X / Ctrl+V — копировать / вырезать / вставить.
- Перетаскивание в папку перемещает файлы; Ctrl при перетаскивании копирует.
- F2 — переименовать; Delete — переместить в корзину с подтверждением; F5 — обновить.
- Alt+← / Alt+→ / Alt+↑ — навигация. Enter и двойной щелчок открывают выбранный объект.
- Можно создавать папки и показывать скрытые файлы. При совпадении имён копия получает новый суффикс, существующие файлы не перезаписываются.
- **Системный проводник ↗** открывает текущую папку для операций средствами ОС, включая работу со ссылками.

## Хранение

Проекты хранятся в `Документы/SolderMap Projects`. В каждой папке находятся `project.json` и изображения сторон. Можно открыть проект из другой папки. Для изолированного запуска допускается переменная `SOLDERMAP_PROJECTS_ROOT`.

Поддерживаемые поля формата версии 4: `name`, `images`, `imageSizes`, `components`, `stages`, `groups`, `doneMap`. Из старых проектов сохраняются изображения, пиксельная разметка, сведения о компонентах и отметки пайки. При открытии файл сохраняется в поддерживаемой схеме, дополнительные поля не переносятся.

Изменения сохраняются автоматически. Закрытие приложения и переход между проектами ожидают завершения записи. Отмена действует на разметку, свойства компонентов и отметки пайки.

## Разработка и сборка

Требуются Node.js и npm.

```bash
npm ci
npm run check
npm run test:electron
npm start
```

`npm run check` проверяет синтаксис и запускает тесты поиска, партий, совместимости данных, масштаба и операций с файлами. `npm run test:electron` выполняет сценарии интерфейса на временном проекте и сохраняет снимки рабочего экрана и проводника в тестовой папке.

Сборка на соответствующей ОС:

```bash
npm run build          # Windows: NSIS и portable
npm run build:linux    # Linux: tar.gz
npm run build:mac      # macOS: dmg и zip
```

`npm run pack` создаёт распакованное Windows-приложение. Результаты находятся в `dist/`; готовые сборки публикуются в GitHub Releases.

## Структура

```text
index.html              Интерфейс рабочего места, диалоги и проводник
css/styles.css          Стили, разметка панели и областей платы
js/app.js               Состояние, пайка, разметка, история, масштаб, проводник
js/assembly.js          Поиск, номиналы, партии, нормализация проекта
js/file-operations.js   Безопасные имена и копирование/перемещение
main.js                 Окно Electron, файловые операции, сохранение и IPC
preload.js              Ограниченный мост renderer → main
test/                   Тесты логики и файловых операций
scripts/                Сценарии проверки интерфейса Electron
assets/                 Значки приложения
docs/DECISIONS.md       Архитектурные решения
```
